What is machine learning?

Instead of writing rules by hand, we show the computer examples and let it learn the rules itself.

Mitchell’s definition: a program learns from experience E on task T if its performance P improves with E.

Three ways machines learn

The difference is the kind of feedback the machine gets: labels, no labels, or rewards.

Supervised

Learns from labeled examples: an input and its correct output.

e.g. spam detection

Unsupervised

Finds hidden groups and patterns in unlabeled data.

e.g. customer segmentation

Reinforcement

An agent learns by trial and error, guided by rewards.

e.g. game-playing AI

Same goal, different feedback.

Supervised: learning from labels

The model learns from examples that come with the correct answer (the label). Regression predicts a continuous number, like a house price or temperature. Classification predicts a category, like spam or not spam.

Common algorithms

Decision Tree

Asks yes/no questions about the features, like a flowchart, until it reaches a decision.

K-Nearest Neighbours

Finds the K closest training points to a new point and takes a majority vote.

Support Vector Machine

Finds the boundary that separates the classes with the widest possible margin.

Overfitting vs underfitting

The goal is a model that generalizes to new, unseen data. Fit a curve to the noisy training points (cyan), then see how it does on new test points (amber).

Training error Test error

Dashed line: the real pattern. Too simple misses it. Too complex memorizes the noise.

Underfitting

The model is too simple to capture the pattern.

Training error: High
Test error: High

Fix: use a more complex model or add features.

Good fit

It captures the real pattern without memorizing noise.

Training error: Low
Test error: Low

Goal: this is where we want to be.

Overfitting

The model memorizes the training data, including its noise.

Training error: Very low
Test error: High

Fix: more data, a simpler model, or regularization.

Unsupervised: finding hidden patterns

No labels. The algorithm finds hidden groups on its own. Main jobs: clustering, dimensionality reduction and anomaly detection.

K-Means clustering

How K-Means works

1. Choose K

How many clusters.

2. Assign

Each point goes to the nearest centroid.

3. Update

Move each centroid to the mean of its points.

4. Repeat

Until the centroids stop moving.

The elbow method picks K. Scale your features; outliers can skew results.

The update rule

Q(s,a) ← Q(s,a) + α [ r + γ · max Q(s′,a′) − Q(s,a) ]

α is the learning rate, γ is the discount factor, ε is explore vs exploit.

Key takeaways

  • Supervised learns from labeled data to predict outputs.
  • Unsupervised finds hidden patterns in unlabeled data.
  • Reinforcement learns from rewards through trial and error.
  • A good model works on new data, so always test on data it has not seen.
